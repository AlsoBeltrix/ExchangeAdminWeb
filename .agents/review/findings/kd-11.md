## Approach

Re-read at `f2a4ef3a` (kd-10's commit; the file is unchanged since `e3cc2d7a`):

- `ExchangeAdminWeb.Tests/MigrationStatusPageTests.cs:2573-2595` - `private static string ExtractBlock(string source, string opener)`:
  `source.IndexOf(opener)`, `source.IndexOf('{', ...)`, then `if (source[i] == '{') depth++; else if (source[i] == '}' && --depth == 0)`
  over the raw text, asserting the opener was found and the braces balanced.
- Its eleven call sites read two different things. Seven openers are C#: `protected override async Task OnInitializedAsync()`
  over the whole page (`:182`), `foreach (var batchName in batchNames)` (`:361`, `:519`), `if (matchedBatch != null)`
  (`:1635`), `if (result.Success && actionBatch != null)` (`:1864`) and `finally` in two loops over method bodies
  (`:1849`, `:2154`). Four are Razor constructs in the page's MARKUP: `@if (canManage && selectedBatches.Count > 0)`
  (`:238`), `@foreach (var batch in GetSelectedBatchesPage())` (`:2239`), `@if (canManage && selectedMailboxes.Count > 0)`
  (`:2335`) and `@foreach (var batch in GetPagedBatches())` (`:2548`).
- kd-3's shared `ClickGateSource.ExtractBlock` reads C# only - its Roslyn code view blanks a component's markup - so it
  serves the seven and cannot serve the four; a plain swap would fail them for a reason that is not a defect.

What changes:

1. **`ClickGateSource.ExtractMarkupBlock(source, opener)`**, shared beside `ExtractBlock`: the same balancing, over a
   markup view that is quote-aware the way `Tags()` is - every quoted attribute value of every tag blanked (through the
   one `WalkTag`), comments blanked as `BlankComments` blanks them, and the component's `@code` regions blanked whole -
   returning the source's own text. Its honest limit is stated: a brace in a C# string in a Razor expression in text
   content (`@("}")`) is still counted. The two share one private `BalancedBlock` and `IndexOfUnblanked` (kd-3's
   `IndexOfCode`, renamed because it now serves both views).
2. **The private copy goes.** `MigrationStatusPageTests.ExtractBlock` keeps its name and its loud failure ("not found, or
   its braces do not balance") and delegates: an opener starting with `@` (a Razor construct in markup) to
   `ExtractMarkupBlock`, anything else to `ExtractBlock`. No call site changes.
3. **Measured, not assumed:** a throwaway instrumented build (not committed) logged the old raw count beside the shared
   lexers at every real call while the Migration page tests ran, and the Migration results were compared test by test
   before and after.

Declared files: `ExchangeAdminWeb.Tests/ClickGateSource.cs`, `ExchangeAdminWeb.Tests/MigrationStatusPageTests.cs`,
`ExchangeAdminWeb.Tests/ClickGateTests.cs` (the guard), this record. No module version: test infrastructure only.

Mutation: the record says "not applicable beyond the kd-3 test" for a pure swap; the markup extractor is new
