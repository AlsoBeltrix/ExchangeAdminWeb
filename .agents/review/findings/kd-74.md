# kd-74: four pages let a second click or a dismissed banner disturb a run in progress

**Severity**: LOW to MEDIUM - found by the kd-72 sweep, a different shape from kd-72. (1) **Licensing Updates**: Apply has no
busy guard, so a double click runs a second bulk licence apply over the same rows - MEDIUM, a write repeated. (2) **Message
Trace Reports**: Download has no busy guard - a double click builds and pushes the file twice. (3) **Self-Service Groups**:
dismissing the result banner mid-run can skip the member-list refresh. (4) **Conference Rooms**: dismissing the result banner
mid-run makes the progress bar report not-succeeded on the two CSV applies (the prog-7 shape: completion read from a
dismissible field).
**Status**: In progress on `fix/kd73-kd74` - (1), (2) fixed and verified on branch; (3), (4) next
**Branch**: `fix/kd73-kd74` (from master `0d6c272b`; worktree `D:\source\ExchangeAdminWeb-wt\kd73-kd74`)
**Commit**: one per sub-item - each is the commit that adds its section below (`git log -- .agents/review/findings/kd-74.md`)
**Reviewer**: implementer (candidate; not yet confirmed by the supervisor)

## Evidence

At `e24887ed`: the kd-72 record's "found and not fixed" list.

## Approach

- (1), (2): a busy guard matching the button's disabled condition, in the kd-72 shape; test: a second click during a run
  is ignored (the stand-in counts calls); mutation: the guard removed.
- (3), (4): the completion and the refresh read from a local, not from the dismissible result field (as ExecuteOnPrem did
  in Mailbox Permissions 1.2.4 / prog-7); test: the banner dismissed mid-run, the refresh still runs / the activity still
  completes succeeded; mutation: the local replaced by the field.
- Patch bump per module. ClickGate / Progress re-anchor if line counts move.
