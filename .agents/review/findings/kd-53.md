## Approach

### As written before the code (branch `fix/psl10-a2y` from `7315733c`; no merge of master, as briefed)

**Verified.** `Components/Pages/AdminBulkJobs.razor` `WriteAudit` (about 353) calls `Audit.LogConferenceRoomAction`, which hardcodes
`["category"] = "ConferenceRooms"` (`Services/AuditService.cs` 309-331), so a Comms-10k or Message Trace job cancelled or
removed from this page files as a Conference Rooms event and a query by category misses it - the misfiling class
`AuditCategoryFilingTests` already guards for three modules. Four processors can own a job (`Program.cs` 102-112):
`ConferenceRooms`, `MessageTrace`, `Migration`, `Comms10k`.

**The change.**
1. `WriteAudit` calls `Audit.LogModuleAction` (the generic one, category a parameter - the method the earlier misfiling fix
   moved three modules to) with `category: job.ModuleId`, or "AdminBulkJobs" when a job carries none, so no row is filed
   under a blank category. `LogModuleAction` has no `oldValues` parameter, so the six job fields are passed through `extra`
   under the `old_` names `LogConferenceRoomAction` gave them: the row keeps every field it had, and only its category
   changes. kd-32's `refusedAt` / `mutationAttempted` ride in the same dictionary.
2. `Components/Pages/AdminEventLog.razor`, the category filter: `MessageTrace` and `Migration` options added (`ConferenceRooms`
   and `Comms10k` are already offered). A category nothing can filter to is the second half of the same defect, which that
   test class states as its rule - and these two become reachable only because of change 1.
3. Tests: `AdminBulkJobsCancelAuditTests` already drives a Comms-10k job, so its rows assert the category is the job's
   module (not ConferenceRooms), with a case for a job that carries none; and a new guard in `AuditCategoryFilingTests`
   reads every `IBulkJobProcessor`'s `ModuleName` by reflection and requires the filter to offer each - it fails today for
   MessageTrace and Migration, and catches a fifth processor added later. Mutations: the fixed category restored; the blank
   fallback dropped; one option removed.
4. Admin Bulk Jobs 1.1.0 -> 1.2.0 (master has 1.1.0 from the batch above).
