### As implemented (implementer, 2026-10-26, branch `fix/a68-kd2`; lines at kd-36's commit, the lines kd-37 touches unmoved since `7e2fb812`)

- The hops, settled by reading them: `Components/Pages/RecipientLookup.razor` 229 calls
  `GetRecipientInfoAsync(target)` with no token, though the activity it runs under has one (`IActivityHandle.CancellationToken`);
  `Services/RecipientLookupService.cs` asks the base for the location (159) and the on-premises size (182);
  `Services/ExchangeServiceBase.cs` `GetMailboxLocationAsync` (729) reaches the on-premises location read (779), which,
  like `GetOnPremMailboxSizeAsync` (627), fetches its credentials through `GetModuleCredentialsAsync` (560; 787 and 636);
  that calls `Services/ModuleCredentialService.cs` `GetCredentialsAsync` (41) / `LookupCredentialsAsync` (50), which calls
  `DelineaService.GetCredentialsBySecretIdAsync` (65) with no token. Delinea already takes one: it throws when its token is
  cancelled and rethrows a cancellation only then (`Services/DelineaService.cs` 132-134, 219-222), so an HTTP timeout
  nobody asked for still comes back as no credential - a warning (kd-14's rule) - with the token threaded.
- Each hop takes a last optional `CancellationToken cancellationToken = default` and passes it on: the page passes
  `activity.CancellationToken` (in place); `GetRecipientInfoAsync`, `GetMailboxLocationAsync(string)`, the on-premises
  location read, `GetOnPremMailboxSizeAsync`, `GetModuleCredentialsAsync`, `GetCredentialsAsync` and
  `LookupCredentialsAsync`. Every other caller passes none and is unchanged. The cloud reads (`RunPooledQueryAsync`)
  take no token and are not changed. `GetModuleCredentialsAsync` is virtual, so the eleven test overrides of it take the
  parameter too. App-wide: yes (`ExchangeServiceBase`, `ModuleCredentialService`); no csproj bump.
- Tests: the real Recipient Lookup service over the stand-in, its credentials through a real `ModuleCredentialService`
  and a real `DelineaService` whose secret request waits until it is cancelled; the lookup is cancelled while that
  request waits and throws a cancellation, where it finished with a warning. The control: a secret request that times
  out on its own is still a warning, and the lookup finishes. Mutation: the token dropped at one hop.
