# kd-20: MigrationStatusPageTests.StripLineComments cuts from // to end of line inside string literals

**Severity**: LOW - latent test-infrastructure defect (the kd-3/kd-12 family). `ExchangeAdminWeb.Tests/MigrationStatusPageTests.cs` about 2471 strips `//` to end of line without lexing strings; it feeds the `finally` scan at about 2154. Today's blocks are unaffected.

## Evidence

At `fix/kd-misc` `1f11fe45`. Trigger: a string literal containing `//` (a URL) in a scanned block. Predicted failure: the rest of the line vanishes from the scan.

## Approach

Re-read at `1f11fe45`:

- `ExchangeAdminWeb.Tests/MigrationStatusPageTests.cs:2471-2472` -
  `private static string StripLineComments(string source) => Regex.Replace(source, @"//[^\r\n]*", "");` - REMOVES from
  any `//` to the end of its line: a URL in a string loses its closing quote and the statements after it, and on a whole
  page a markup `https://` takes the rest of its tag. Block and Razor comments are left in.
- 46 callers, two kinds of input: the whole page (`StripLineComments(ReadPage())`, e.g. `:103`, `:2139`) and C# method or
  member bodies (`StripLineComments(GetMethodBody(...))`, e.g. `:2149`, which feeds the `finally` scan at `:2154`).
- kd-12's view, `ClickGateSource.BlankComments`, reads its input as a component - right for the page, wrong for a body,
  which has no @code block and would be read as all markup; `RazorSyntax.CommentsBlanked` reads a body as C#.

What changes: `StripLineComments` blanks comments through the lexers - a page (anything holding an @code block) through
`ClickGateSource.BlankComments`, a body through `RazorSyntax.CommentsBlanked` - blanked, not deleted, so offsets hold;
block and Razor comments go too, which is what its callers want ("a comment explaining one of these rules would
otherwise be read as code"). The name is kept so the 46 callers did not move; its summary says what it does now.

Declared files: `ExchangeAdminWeb.Tests/MigrationStatusPageTests.cs` (the helper and the guard), this record.

Mutation: the line cut restored.
