## Approach

Written before the code, against `26e8cd9b`. The brief: the preview says the list does not exist and that the row will
be refused until it is created in Exchange Online, naming it; the page is line-keyed, so edit in place.

**Where the promise is made.** `Components/Pages/ConferenceRooms.razor:204` marks a row whose building has no room list
with a blue "new" badge, and the preview adds no warning for it (`:1207-1210` warn only about a legacy list and a stray
city-named one). Until aud-a2ab that was true - the apply created the list. It no longer does, so the operator is shown
"new" and told only after applying that the row was refused.

**The change, in two places and in place.**

- `:204` - the badge becomes a red "does not exist", beside the list's name which the cell already renders;
- `:1208` - a warning in the column the preview already shows: the list by name, that the row will be refused, and that
  the operator creates it in Exchange Online and re-runs. The wording follows the refusal's own advice
  (`ConferenceRoomService.RoomListDoesNotExistRefusal`), said before the apply instead of after it.

**Keeping the line count.** The page is keyed by line number by `ClickGateRegistry` and `ProgressRegistry`, so a warning
cannot simply be added. The legacy warning beside it (`:1207-1208`, a two-line `if`) is folded onto one line and the new
one takes the line freed: two lines before, two after, 1758 in total unchanged, and the legacy text itself untouched.
`ClickGateTests` asserts the count, so a slip fails the suite rather than silently moving every entry below.

**Merge.** Another agent edited this page in place while this branch was stopped. Master's version differs from this
branch's at twelve hunks, all at `:508` and beyond; both lines this change touches are identical in the two, so the edit
lands cleanly - checked with `git diff HEAD master -- Components/Pages/ConferenceRooms.razor` before editing.

**Files to change.** `Components/Pages/ConferenceRooms.razor`; a new
`ExchangeAdminWeb.Tests/ConferenceRoomMissingListPreviewTests.cs`; `Modules/ModuleCatalog.cs` (2.17.0 -> 2.18.0); this
record.
